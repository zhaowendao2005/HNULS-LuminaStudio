# 来源扩展约定

## 当前边界

当前 skill 的目标框架固定为：

- 输出：`Vue + Tailwind CSS`

当前优先支持的来源是：

- Elements 导出的 HTML 片段
- 原型节点本体 / 节点面板这类局部模板片段

## 后续扩展方向

后续如果来源变成 React 片段，扩展方式应该是：

- 保持输出仍然是 Vue
- 只新增“来源规整”规则
- 不改任务域规则
- 不改 Vue 输出契约

也就是说，未来新增的是“React 片段如何清洗并映射到 Vue 模板”的模块，而不是再造一个新的目标框架 skill。

## React 片段纳入时的处理方式

届时新增模块时，重点补这些内容：

- JSX / TSX 语法清洗
- `className` 到 `class` 的映射
- React 条件渲染到 Vue 条件渲染的映射
- React 事件到 Vue 事件的映射
- hooks 状态到 `script setup` 的最小化映射

但以下内容继续沿用当前 skill：

- 任务域命名
- 标签类优先
- 局部样式边界
- “先忠实复刻，再最小重构”的执行顺序

## 维护规则

如果后续真的加入 React 来源支持：

- 在 `SKILL.md` 的描述中补充触发条件
- 新增单独模块，不要把所有来源细节堆进索引页
- 保持索引页只负责导航和总原则
