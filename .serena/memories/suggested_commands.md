Windows environment. Common project commands: `pnpm install`, `pnpm dev`, `pnpm build:win`, `pnpm build:mac`, `pnpm build:linux`. For typecheck: `pnpm exec tsc -p tsconfig.json --noEmit`. For normal-chat targeted tests use `pnpm exec vitest run src/renderer/src/stores/normal-chat/conversation/conversation.mock.test.ts`. For OrchestraFlow checks use `pnpm test:orchestraflow` and `pnpm lint:orchestraflow`. For targeted lint on modified files use `pnpm exec eslint <paths>` and formatting via `pnpm exec prettier --write <paths>` if needed.
