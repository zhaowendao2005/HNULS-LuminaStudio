HNULS-LuminaStudio is an Electron + Vue + TypeScript desktop app using pnpm. The main workspace of interest is LuminaStudio/. Renderer state is organized under src/renderer/src/stores, with normal-chat stores under src/renderer/src/stores/normal-chat and UI under src/renderer/src/views/LuminaApp/Maincontent/NormalChat. Preload cross-process/public types are exported from src/preload/types and re-exported via src/preload/index.d.ts. OrchestraFlow has its own shared-type architecture under src/Public/ShareTypes/Orchestraflow-types and should not be mixed with normal-chat work.
